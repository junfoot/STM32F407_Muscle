# 产品介绍
## 产品概述
+ 产品模组由1个主机和若干个从机组成，最多可连接32个从机。
+ <font style="color:#181818;">从机集成高精度的陀螺仪、加速度计、地磁场传感器，采用高性能的微处理器和先进的动力学解算与卡尔曼动态滤波算法，能够快速求解出从机当前的实时运动姿态。</font>
+ <font style="color:#181818;">采用先进的数字滤波技术，能有效降低测量噪声，提高测量精度。</font>
+ <font style="color:#181818;">从机内部集成了姿态解算器，配合动态卡尔曼滤波算法，能够在动态环境下准确输出从机的当前姿态，姿态测量精度0.2度，稳定性极高，性能甚至优于某些专业的倾角仪！</font>
+ <font style="color:#181818;">高性能cortex-M4内核处理器运行主频高达168MHZ，兼顾低功耗与高性能。</font>
+ <font style="color:#181818;">射频2.4G无线传输，传输速率快，最高有效速率可达256kbps。</font>



## 产品特点
+ <font style="color:black;background-color:#FFFFFF;">从机</font><font style="color:black;background-color:#FFFFFF;">集成高精度的陀螺仪、加速度计、地磁场传感器，采用高性能的微处理器和先进的动力学解算与卡尔曼动态滤波算法，能够快速求解出模块当前的实时运动姿态。</font>
+ <font style="color:black;background-color:#FFFFFF;">采用先进的数字滤波技术，能有效降低测量噪声，提高测量精度。</font>
+ <font style="color:black;background-color:#FFFFFF;">从机</font><font style="color:black;background-color:#FFFFFF;">内部集成了姿态解算器，配合动态卡尔曼滤波算法，能够在动态环境下准确输出模块的当前姿态，姿态测量精度0.2°，稳定性极高，性能甚至优于某些专业的倾角仪。</font>
+ <font style="color:black;background-color:#FFFFFF;">Z轴航向角加入地磁传感器滤波融合，解决了6轴算法中，由于陀螺仪积分的漂移引起的累计误差，可长期稳定输出航向角数据。</font>**<font style="color:black;background-color:#FFFFFF;">注意：要由于有磁场检测，使用前需要校准，而且使用时需要远离磁干扰区域、电子设备、磁铁、扬声器等硬磁性物体至少20cm的距离。</font>**
+ <font style="color:rgb(24, 24, 24);">工作电流：≈  15mA，待机电流  13uA。</font>
+ <font style="color:rgb(24, 24, 24);">数据接口：波特率460800。</font>
+ <font style="color:black;background-color:#FFFFFF;">输出内容包含三轴加速度、三轴角速度、三轴磁场、三轴角度、从机电量</font><font style="color:#181818;">。</font>
+ <font style="color:black;background-color:#FFFFFF;">4层PCB板工艺，更薄、更小、更可靠。</font>
+ <font style="color:#181818;">2.4G射频无线传输</font>

<font style="color:rgb(51, 51, 51);">⑦设置保存。</font>

## 从机连接与配置
1.从机按开机键进行开机，开机后会闪烁绿灯，如果开机指示灯没有反应请充电后再试。

<font style="color:#DF2A3F;">注：第1次使用的时候从机单个开机依次进行配置，不要一次性把所有从机都开机，不然无法进行配置。</font>

<img src="https://cdn.nlark.com/yuque/0/2024/jpeg/27793718/1722912385951-a1d67e7b-2f13-4254-9af8-592f58a31272.jpeg?x-oss-process=image%2Fcrop%2Cx_0%2Cy_126%2Cw_798%2Ch_542" width="342.9942932128906" title="" crop="0,0.1569,0.9972,0.8347" id="uaa6759d4" class="ne-image">

<font style="color:rgb(51, 51, 51);">2.打开维特</font>[**智能上位机**](https://wit-motion.yuque.com/wumwnr/aqvq6y/qngktvx5grz81zkq)<font style="color:rgb(51, 51, 51);">软件。</font>

①<font style="color:rgb(51, 51, 51);">选择WT9011DCL-RF的型号。</font>

<font style="color:rgb(51, 51, 51);">②点击搜索设备。</font>

<font style="color:rgb(51, 51, 51);">③勾选Master连接适配器。</font>

<font style="color:rgb(51, 51, 51);">④勾选从机。</font>

<font style="color:rgb(51, 51, 51);">⑤第1次连接的时候，所有从机ID都是01，所以第1次配置时只勾选01的从机ID，然后打开配置界面。</font>

<font style="color:rgb(51, 51, 51);">⑥确认配置界面是否“在线”，“在线”的情况下进行下一步。</font>

<font style="color:rgb(51, 51, 51);">⑦连接多个从机的时候，需要修改默认ID，ID配置范围0~31，即00、01、02......30、31。</font>

<font style="color:#DF2A3F;">注：搜索设备会出现多个设备选项，只需要关注id为01的设备即可，所有从机出厂时设备id默认都为01。</font>

⑨配置好所有从机后重新进行搜索，勾选Master和相应从机ID就可以显示数据。<img src="https://cdn.nlark.com/yuque/0/2024/png/27793718/1722925010626-03b90193-9ce6-4399-bdfc-42376f2dc72c.png" width="1309.0908807171284" title="" crop="0,0,1,1" id="ued839059" class="ne-image">
